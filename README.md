# ДезКонтроль (pestcontrol) — расчёт средств дезинсекции/дератизации и планы объектов

Android-приложение (Kotlin + Jetpack Compose) для сотрудников служб дезинсекции и дератизации.

## Возможности

- **Объекты** — список обслуживаемых объектов (название, адрес, счётчики этажей и ловушек)
- **Расчёт средств** — по вредителю (тараканы / крысы / мыши), уровню заражённости и площади: количество геля, родентицида, точек нанесения, объём рабочего раствора, число клеевых ловушек и контейнеров
- **Планы объектов** — рисование плана пальцем, подписи ориентиров, маркеры ловушек и нор, поддержка этажей
- **База ловушек** — все ловушки по всем объектам: фильтры по типу и статусу (Активна / На замене / Снята), заметки, дата установки

Включает общий модуль `common`: редактор планов (рисование, этажи, ориентиры, маркеры) с локальным JSON-хранилищем.

## Локализация

10 языков: русский, английский, испанский, французский, немецкий, португальский, китайский, арабский (RTL), хинди, армянский.

## Сборка и запуск

- Android Studio (Koala+) или `gradlew.bat :pestcontrol:assembleDebug` (JDK 17+, Android SDK 34)
- APK: `pestcontrol\build\outputs\apk\debug\`
- minSdk 24 (Android 7.0+)

## Тесты

- Компонентные (JVM): `gradlew.bat test` — модель планов (common), расчёт средств (`DosageCalculator`)
- E2E (нужен эмулятор/устройство): `gradlew.bat connectedDebugAndroidTest` — 7 сценариев: объект → ловушка → база, расчёт, рисование + undo, лейблы, этажи, повторный тап-удаление маркера, смена статуса ловушки. Если UTP-раннер падает с gRPC-ошибкой:
  `adb shell am instrument -w com.firebug.pest.test/androidx.test.runner.AndroidJUnitRunner` после установки debug- и androidTest-APK.

## Данные

Локально, в JSON: `filesDir/plan_objects.json`.
